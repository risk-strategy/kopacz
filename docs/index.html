01.Overview

kopacz encapsulates authenticated, compressed streams inside standard DNS queries and responses. Clients hold only the relay's 32-byte X25519 static public key and complete a 1-RTT Noise_NK (es + ee) handshake with forward secrecy, eliminating shared symmetric secrets so a compromised client cannot impersonate the relay or decrypt peer handshakes.

Handshake
1-RTT Noise_NK (es+ee)
Carriers
UDP/53 TXT/AAAA, DoH
Stream AEAD
ChaCha20-Poly1305 + LZ4

02.Architecture

+---------------+   UDP/53 / DoH   +--------------------+     DNS      +------------------+   Tor / TCP   +---------------+
| Kopacz Client | ===============> | Recursive Resolver | -----------> | Authoritative NS | ------------> | Kopacz Relay  |
| (C/Py/JS/Sh)  | <=============== | (1.1.1.1 / 8.8.8.8)| <----------- |  (*.t.zone.tld)  | <------------ | (Apps 01..04) |
+---------------+    TXT / AAAA    +--------------------+              +------------------+               +---------------+
  • Noise_NK Session 56-byte SYN (ephemeral pubkey + encrypted UTC timestamp) and 48-byte SYN-ACK with 64-packet anti-replay window, selective retransmission, and LZ4 frame compression.
  • DNS Carrier Packs fragments into Base32 DNS labels with an 8-character session tag and unpacks Base32/Base64 TXT or synthesized IPv6 AAAA responses.
  • Relay Apps Multiplexed services behind the relay: CONNECT SOCKS5 proxy (0x01), TCP/SSH bridge (0x02), E2E dead-drop messaging (0x03), and Reader/Full web fetch (0x04).
  • Standalone Clients Zero-dependency implementations in C99, JavaScript (browser DoH web.html + Node CLI), pure-CLI Bash (openssl + dig + awk), .NET Core PowerShell, and Python.

Field Description
Flags (8b) Control bitfield: SYN (0x80), FIN (0x40), ACK (0x20), DATA (0x10), POLL (0x08), FRAG (0x04), MORE (0x02), COMP (0x01).
Stream ID (16b) Logical stream identifier multiplexed within an authenticated session tag.
Sequence (16b) Monotonic packet counter bound into ChaCha20-Poly1305 AAD and ARQ reassembly.
Frag Index / Total Zero-based fragment index and total fragment count for DNS label MTU splitting.
Aux / Reserved (8b) Piggybacked ACK low-byte, POLL nonce low-byte, or client downstream MTU request on SYN.
Control Auth Tag Unencrypted control frames (POLL, ACK, FIN) carry an 8-byte truncated Poly1305 tag over the header.
